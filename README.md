# Pokémon Card Web App

A web application built with React and Vite that allows users to search for Pokémon cards using the Pokémon API. The app is hosted on Netlify.

## 🚀 Features
- 🔍 **Search for Pokémon** by name
- 📜 **View detailed Pokémon card information**
- ⚡ **Fast and responsive UI with React & Vite**
- 🌐 **Hosted on Netlify for easy access**

## 🛠️ Technologies Used
- React.js
- Vite
- Pokémon API
- Netlify (for deployment)
- https://ppokemonscards.netlify.app/
